# HWWGS — Corporate Business Website

A modern, responsive corporate website for **HWWGS**, showcasing three core business areas: Management Consulting, Information Technology, and Real Estate.

The website is designed with a clean corporate layout, professional imagery, responsive navigation, and a user-friendly contact form to help visitors explore services and make enquiries.

## 🌐 Live Demo

- **Website:** https://hwwgs.vercel.app/.
- **GitHub Repository:** https://github.com/BIMBALLER/hwwgs.

## ✨ Features

- **Modern UI Design:** Professional layout with a corporate colour palette inspired by the HWWGS logo.
- **Responsive Design:** Optimised for desktop, tablet, and mobile devices.
- **Tailwind CSS:** Utility-first styling for a clean and maintainable interface.
- **Interactive Navigation:** Sticky desktop navigation and collapsible mobile menu.
- **Hero Section:** Eye-catching introduction with a background image and clear calls to action.
- **About Section:** Introduction to the company's mission, vision, and approach.
- **Services Section:** Dedicated sections for the company's three core service areas.
- **Visual Gallery:** Professional imagery representing business, technology, and property.
- **Contact Form:** Collects visitor details and prepares an enquiry through the visitor's default email application.
- **Dynamic Copyright Year:** Automatically updates the year in the footer.
- **SEO Basics:** Includes a page title, meta description, and semantic HTML structure.
